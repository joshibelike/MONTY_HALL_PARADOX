# Парадокс Монти Холла

Одностраничный сайт: интерактивная игра, разбор парадокса и результаты симуляции на 10 000 игр.
Сборки нет — это обычные статические файлы, все пути относительные.

## Запуск локально

Откройте `index.html` в браузере или поднимите любой статический сервер:

```bash
python -m http.server 5173
```

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и отправьте в него содержимое папки:

   ```bash
   git init -b main
   git add .
   git commit -m "Парадокс Монти Холла"
   git remote add origin https://github.com/<имя>/<репозиторий>.git
   git push -u origin main
   ```

2. В репозитории откройте **Settings → Pages**.
3. В блоке **Build and deployment** выберите **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через минуту-две сайт будет доступен по адресу `https://<имя>.github.io/<репозиторий>/`.

## Пересчёт симуляции

```bash
node scripts/simulate.js
```

Скрипт перезаписывает `results.txt` и `js/simulation-data.js`. Результат воспроизводим: генератор случайных чисел использует фиксированный seed.
