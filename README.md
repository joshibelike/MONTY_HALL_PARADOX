# Парадокс Монти Холла

Одностраничный сайт: интерактивная игра, разбор парадокса и результаты симуляции на 10 000 игр.
Сборки нет — это обычные статические файлы, все пути относительные.

## Пересчёт симуляции

```bash
node scripts/simulate.js
```

Скрипт перезаписывает `results.txt` и `js/simulation-data.js`. Результат воспроизводим: генератор случайных чисел использует фиксированный seed.
